# NLP Coursework Repository
This repository contains a collection of Natural Language Processing (NLP) coursework assignments completed using Python and common NLP libraries such as NLTK, Scikit-learn, TextBlob, VADER, Gradio, and Hugging Face Transformers.

## Coursework Overview
### Assignment 1 — Text Preprocessing and Document Similarity

Implemented a full NLP preprocessing pipeline using NLTK, including:

- Tokenization
- Stop word removal
- Stemming
- TF-IDF document-word matrix generation
- Pairwise cosine similarity calculation between documents
### Assignment 2 — IMDB Sentiment Classification

Performed binary sentiment classification on the IMDB movie review dataset using:

- Naïve Bayes classification
- Text preprocessing and vectorization
- Classification accuracy evaluation using Scikit-learn
### Assignment 3 — Sentiment Analysis Comparison

Conducted sentiment analysis using:

- TextBlob
- VADER Sentiment Analyzer

Compared sentiment prediction performance and analyzed differences between the approaches on positive and negative text datasets.

### Assignment 4 — Conversational Chatbot

Built a lightweight conversational AI chatbot using:

- microsoft/DialoGPT-medium
- Gradio web interface
- Hugging Face Spaces deployment

The chatbot generates conversational responses without additional fine-tuning or backend infrastructure.
